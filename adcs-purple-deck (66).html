1.What is Satellite Attitude?

Attitude describes how a spacecraft is oriented in space and how its body axes are aligned with a chosen reference frame.

Attitude definition

Attitude represents spacecraft orientation—defined as the directional unit vectors to which body axes must align relative to a reference frame.

Body vs. reference frames

The system maps the satellite’s internal body coordinate triad [b₁, b₂, b₃] relative to an orbital or inertial reference frame [n₁, n₂, n₃] to maintain target alignment.

Why it matters

Accurate attitude knowledge lets payloads point, communicate, collect imagery, and generate power with the correct face toward the target.

Three inertial axes [n₁, n₂, n₃] and three body axes [b₁, b₂, b₃] describe the spacecraft attitude.

ADCS protects the commanded attitude when the environment pushes the spacecraft away from its reference and when a burn must be precisely oriented.

2.5.1 External disturbances

Rejecting environmental torques

Solar radiation pressure and atmospheric drag in low Earth orbit are different effects. Along with gravity-gradient torque, they can disturb attitude and accumulate momentum. ADCS estimates and rejects these disturbances.

Pointing the spacecraft for the burn

TRIAD creates a right-handed coordinate frame from two non-collinear vector observations in both frames, then aligns the two triads.

4.3 Attitude Determination Methods
4. Wahba’s Problem

Wahba’s problem is the mathematical formulation behind deterministic attitude estimation.

1. Unit-Vector Observations

For each sensor observation k, we have a measured body vector and a known inertial reference vector.

‖b̂kB‖ = ‖n̂kN‖ = 1

2. Wahba’s Cost Function

J([BN]) = ½ Σk=1N wk ‖b̂kB − [BN]n̂kN‖²

3. Physical Meaning

The correct attitude is the rotation that makes the predicted body vectors agree with the sensor measurements. The weights wk express confidence in each sensor.

4. Deterministic Versus Dynamic

Measurements taken at one time form a deterministic attitude solution. Combining observations over time with gyro information becomes a dynamic attitude-estimation or filtering problem.

5.Control System

5.1 Actuators
Magnetorquer — Physical Principle

Actuators convert the controller command into a physical torque that changes the spacecraft attitude.

1. Actuator Role

A magnetorquer is an electromagnetic coil. When current flows through the coil, it creates a magnetic field and an equivalent magnetic dipole moment. That dipole interacts with Earth’s magnetic field and produces a torque that rotates the spacecraft toward the commanded attitude. It changes attitude; it does not generate translational Δv.

2. Magnetic Dipole Moment

The current determines the strength of the dipole, while the coil axis determines its direction.

m = N I A n̂

N: number of turns, I: coil current, A: coil area, n̂: coil-axis direction.

MTQ800 magnetic torque rod actuator: a coil assembly that generates a commanded magnetic dipole moment.

5.Control System

5.1 Actuators
Magnetorquer — Torque Generation and Current Command

The commanded current sets the magnetic dipole, which interacts with Earth’s field to generate the control torque.

3. Generated Control Torque

The magnetic dipole interacts with Earth’s local magnetic-field vector B. Their cross product produces the control torque that changes the spacecraft attitude.

τM = m × B

The torque is perpendicular to B; therefore, a magnetorquer cannot command an arbitrary three-axis torque at one instant.

4. Compute the Required Current

The controller first computes the required dipole moment from the desired torque. The corresponding coil current is then calculated from the actuator properties.

m = (B × τd) / ‖B‖² Ii = mi / (NiAi)

For detumbling, the B-dot law directly commands the dipole using the measured change in the magnetic field:

m = −KB Ḃ    →    τM = −KB(Ḃ × B)
Physical chain: commanded attitude → control law → required current I → coil magnetic field → interaction with Earth’s B → generated torque → spacecraft attitude change.

Magnetorquer actuator reference: the magnetic torque rod interacts with Earth’s field to control spacecraft attitude.

5.Control System

5.1 Actuators
Reaction Wheel — Momentum Exchange Actuator

A reaction wheel changes spacecraft attitude by exchanging angular momentum internally, without expelling propellant or applying an external torque.

1. Operating Principle

The wheel is mounted inside the spacecraft and driven by an electric motor. When the wheel accelerates, the spacecraft body responds with an equal and opposite angular-momentum change.

Htotal = Jsωs + JwΩw ≈ constant

2. Opposite Rotation

If the reaction wheel spins clockwise, the spacecraft rotates counter-clockwise. The actuator changes only the wheel’s angular speed Ωw around its fixed axis; it does not steer the wheel axis itself. The wheel absorbs or releases angular momentum to reduce an unwanted body rate and stabilize the commanded attitude.

τs = −Jw Ω̇w

5.Control System

5.1 Actuators
Control Moment Gyroscope

A CMG uses a high-speed spinning rotor and a gimbal to redirect stored angular momentum and generate a non-propulsive control torque.

1. Operating Principle

The rotor spins at an approximately constant speed and stores angular momentum h. Rotating the gimbal changes the direction of that momentum vector, so the spacecraft platform responds with a control torque that changes its attitude without expelling propellant.

h = Jw Ω ĥ     τCMG = ωg × h

2. Gimbal Steering

When the gimbal is vertical, the platform is at the equilibrium reference. Changing the gimbal angle θ redirects h; the gimbal rate controls the magnitude of the generated torque, while the gimbal axis sets its direction.

ωg = θ̇ ĝ    →    τCMG = θ̇(ĝ × h)

5.Control System

5.1 Actuators
Thrusters — Propulsive Attitude Actuator

Thrusters expel propellant to create an external force. Selected jets or opposing pairs generate spacecraft torque and can also provide translational Δv.

1. Actuator Role

ADCS commands a short firing pulse or a matched pair of thrusters. The exhaust force changes the spacecraft angular momentum; firing at a distance from the center of mass creates the required attitude-control torque.

F = ṁve     τ = r × F

Unlike reaction wheels and magnetorquers, thrusters can generate both attitude torque and translational Δv.

2. Main Propellant Families

  • Cold gas: nitrogen, butane, or stored vapor; simple and clean, but lower performance.
  • Monopropellant: hydrazine or green propellants such as AF-M315E and LMP-103S.
  • Bipropellant: separate fuel and oxidizer, such as MMH/NTO or LOX/methane; higher performance with more complexity.
  • Electric: xenon, krypton, or iodine accelerated electrically; high specific impulse but usually low thrust.
Selection trade-off: required thrust and response time ↔ specific impulse, power, storage, toxicity, and system complexity.

5.Control System

5.2 Control Algorithms
Angular Momentum and the Transport Theorem

These two relations connect the spacecraft angular momentum to the torque measured in the inertial frame and lead directly to Euler’s rotational equation.

1. Angular momentum
H = Jω

For a rigid spacecraft, the angular-momentum vector H equals the inertia matrix J multiplied by the body angular-velocity vector ω.

2. Transport theorem
(dH/dt)I = (dH/dt)B + ωB/I × H

The derivative seen from the inertial frame equals the derivative seen from the rotating body frame plus the rotation of the body frame itself.

Rigid-body link: because the inertia matrix is constant in body coordinates, (dH/dt)B = Jω̇, so the transport theorem produces the gyroscopic coupling term.

Frame meanings

  • I: inertial frame, fixed relative to space.
  • B: body frame, fixed to the spacecraft.
  • J: spacecraft inertia matrix.
  • ωB/I: body angular velocity relative to the inertial frame.
  • ×: vector cross product that represents frame-rotation coupling.

Torque relation

τ = (dH/dt)I

Substituting H = Jω gives:

τ = Jω̇ + ω × (Jω)

This is the body-frame Euler equation used by the control algorithm.

Euler Equation of Motion

The control algorithm uses the spacecraft rotational dynamics to convert actuator torque into the desired change in attitude and angular velocity.

Spacecraft rotational dynamics
J ω̇ + ω × (Jω) = τcontrol + τdisturbance H = Jω    and    τ = dH/dt
τx = Jxxω̇x + (Jzz − Jyy)ωyωz τy = Jyyω̇y + (Jxx − Jzz)ωzωx τz = Jzzω̇z + (Jyy − Jxx)ωxωy
Control meaning: the actuators generate τcontrol; the controller accounts for the gyroscopic coupling term ω × (Jω) and rejects environmental disturbances.

From dynamics to control

The attitude-control law compares the commanded and measured attitude, computes the required torque, and sends actuator commands to reaction wheels, magnetorquers, CMGs, or thrusters.

Meaning of the terms

  • J: spacecraft inertia matrix, including moments and products of inertia.
  • ω: body angular-velocity vector measured with respect to the inertial frame.
  • H = Jω: angular-momentum vector.
  • τcontrol: torque produced by the selected actuators.
  • τdisturbance: external torque from gravity-gradient, aerodynamic drag, solar radiation pressure, or magnetic effects.

Inertia matrix

J = [ Jxx Jxy Jxz ]
    [ Jyx Jyy Jyz ]
    [ Jzx Jzy Jzz ]

For principal body axes, the products of inertia are zero and J becomes diagonal.

           [−sinα  cosα ]

2. Apply the same idea to each 3D axis pair

For the 3-2-1 sequence, use yaw ψ about axis 3, pitch θ about axis 2, and roll φ about axis 1.

C3(ψ) — yaw[ cψ  sψ  0 ]
[−sψ  cψ  0 ]
[ 0    0    1 ]
C2(θ) — pitch[ cθ  0  −sθ ]
[ 0    1    0 ]
[ sθ  0   cθ ]
C1(φ) — roll[ 1    0    0 ]
[ 0   cφ  sφ ]
[ 0  −sφ  cφ ]

3. Multiply the transformations

Using the convention in the reference, the matrix below maps inertial-frame components into body-frame components. The rightmost rotation acts first; cα = cosα and sα = sinα.

vB = CBNvN,   CBN = C1(φ)C2(θ)C3(ψ) CBN = [ cθcψ   cθsψ   −sθ ]
          [ sφsθcψ−cφsψ   sφsθsψ+cφcψ   sφcθ ]
          [ cφsθcψ+sφsψ   cφsθsψ−sφcψ   cφcθ ] vN = CNBvB = (CBN)TvB

4. Rotation-matrix properties

  • CTC = I
  • C−1 = CT
  • det(C) = +1
  • Rows and columns are orthonormal
  • Lengths and angles are preserved
  • No scaling or shear is introduced

‖Cv‖ = ‖v‖    and    (Cu)·(Cv) = u·v

5. Angular rate → 3-2-1 Euler-angle rates

Let ωB = [ω1, ω2, ω3]T be the body angular-rate vector. For Euler angles ordered as [ψ, θ, φ]:

[ ω1 ] [ −sinθ 0 1 ] [ ψ̇ ] [ ω2 ] = [ sinφ cosθ cosφ 0 ] [ θ̇ ] [ ω3 ] [ cosφ cosθ −sinφ 0 ] [ φ̇ ] ψ̇ = (sinφ ω2 + cosφ ω3)/cosθ θ̇ = cosφ ω2 − sinφ ω3 φ̇ = ω1 + tanθ(sinφ ω2 + cosφ ω3)

At cosθ = 0 (θ = ±90°), the inverse relation is singular: this is the 3-2-1 gimbal-lock condition.

Takeaway: the DCM describes orientation; the kinematic rate equation converts measured body rates into the time derivatives of the Euler angles used by the controller.
